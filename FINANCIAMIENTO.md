## 1. Requisitos de Stellar Community Fund (SCF)

El Stellar Community Fund (SCF) es un programa del ecosistema Stellar que apoya proyectos que buscan construir, integrar o ampliar soluciones relacionadas con la red Stellar.

Para el programa SCF Build Award, la información oficial indica apoyos de hasta **$150,000 USD equivalentes en XLM**, sujetos a las reglas y condiciones de la convocatoria correspondiente.

### Criterios de evaluación

Entre los aspectos considerados se encuentran:

- **Product Market Fit:** demostrar que existe una necesidad real y que la solución propuesta tiene sentido para sus usuarios.
- **Track Specific Criteria:** cumplir con los criterios particulares del track.
- **Submission Quality:** presentar una propuesta clara y completa.
- **Use of Stellar:** explicar de manera concreta cómo se utilizará Stellar.
- **Integration Plan:** presentar un plan viable para integrar la tecnología.
- **Ready to Build:** demostrar preparación técnica y organizativa.
- **Budget & Tranches:** presentar un presupuesto razonable y relacionarlo con avances verificables.

### Relación con nuestro proyecto

Nuestro proyecto podría utilizar Stellar en una etapa futura para mecanismos transparentes de apoyo, registro o financiamiento relacionados con el proyecto.

Actualmente todavía nos encontramos en una etapa de investigación, organización y definición del producto, por lo que no afirmamos cumplir todos los requisitos técnicos de una postulación.

## 2. Funcionamiento de Drips Protocol

Drips es un protocolo basado en Ethereum y redes compatibles con EVM que permite apoyar proyectos de código abierto mediante flujos continuos de fondos.

### Streaming de fondos

Un stream permite distribuir fondos progresivamente durante un periodo de tiempo, en lugar de realizar únicamente una transferencia única.

El receptor puede reclamar los fondos disponibles de acuerdo con la configuración del flujo.

### ¿Qué necesita un proyecto para recibir fondos?

Para reclamar un proyecto de código abierto se requiere, entre otros elementos:

1. Un repositorio de GitHub.
2. Realizar el proceso de reclamación del proyecto.
3. Una dirección compatible con Ethereum.
4. Verificar la propiedad del repositorio mediante `FUNDING.json`.
5. Contar con ETH suficiente para las operaciones que requieran gas.
6. Configurar la distribución de fondos cuando corresponda.

También es posible utilizar una wallet multisig para administrar los fondos cuando participan varias personas.

### Límites y condiciones

Drips requiere configuración y verificación; los fondos no se reciben automáticamente.

Además:

- Las operaciones blockchain pueden requerir gas.
- Se debe verificar la propiedad del proyecto.
- La administración de fondos depende de las configuraciones realizadas.
- Una Drip List puede manejar hasta **200 receptores**.
- Drips utiliza infraestructura Ethereum/EVM y no es un mecanismo nativo de Stellar.

## 5. El hueco honesto

Actualmente **NO cumplimos todos los requisitos técnicos necesarios para presentar el proyecto como listo para recibir financiamiento on-chain**.

Todavía no contamos con:

- MVP funcional terminado.
- Integración implementada con Stellar.
- Pruebas de una solución sobre Stellar/Soroban.
- Wallet institucional o del proyecto.
- Proyecto reclamado en Drips.
- `FUNDING.json` configurado para Drips.
- Evidencia suficiente de usuarios utilizando el MVP.
- Presupuesto definitivo.
- Plan técnico definitivo para utilizar blockchain.

Por lo tanto, no afirmamos ser beneficiarios del SCF ni de Drips.

## 6. Conclusión

La investigación permitió identificar que Stellar Community Fund y Drips son mecanismos diferentes que pueden complementar un proyecto de código abierto.

El SCF puede proporcionar financiamiento a proyectos que cumplan sus criterios y presenten un plan verificable. Drips permite establecer mecanismos de apoyo financiero continuo para proyectos de código abierto mediante infraestructura basada en Ethereum/EVM.

Para nuestro proyecto de preservación de la lengua materna de Santa María Cuquila, primero se debe completar y validar el MVP. Posteriormente se evaluará si una integración con Stellar o Drips aporta un beneficio real.

Por ello, el equipo identifica sus brechas actuales y establece acciones y fechas para cerrarlas antes de considerar una postulación formal.
