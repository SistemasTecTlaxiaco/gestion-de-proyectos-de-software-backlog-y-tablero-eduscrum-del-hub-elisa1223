# HU-03: Reportar una incidencia del servicio de agua

## Problemática relacionada

PROB-02: Seguimiento y atención de incidencias relacionadas con el servicio de agua.

## Historia de usuario

**Como usuario del servicio de agua potable, quiero reportar una incidencia indicando su ubicación y descripción, para que la autoridad responsable pueda conocer el problema y darle seguimiento.**

## Rol

Usuario del servicio de agua potable.

## Criterios de aceptación

- [ ] El usuario puede registrar una incidencia.
- [ ] El sistema solicita la ubicación del problema.
- [ ] El usuario puede describir la incidencia.
- [ ] El sistema genera un identificador único para el reporte.
- [ ] El sistema confirma que el reporte fue registrado.
- [ ] El reporte queda disponible para su seguimiento.

## Alcance

La historia contempla únicamente el registro de la incidencia. No incluye la reparación del problema ni la asignación automática del personal responsable.

## Consideración tecnológica

El sistema deberá mantener un registro ordenado de las incidencias y sus actualizaciones. Posteriormente se analizarán las tecnologías que permitan proporcionar trazabilidad sin afectar la privacidad de los usuarios.
